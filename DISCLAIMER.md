# Disclaimer

This repository is **research documentation** for *Need for Speed Underground* (PC).

- It does **not** contain `Speed.exe`, game assets, cracked binaries, or libraries.
- You need your **own legitimate copy** of the game to compare addresses or build mods.
- Function bodies are reconstructed C from a disassembler (Ghidra), plus a smaller set of compiler-checked rewrites. They are **not** Electronic Arts source code.
- Folder names such as `feng/`, `eagl/`, `realcore/` are **research labels** from strings and call patterns, not an official engine map.
- Electronic Arts and Black Box own the original game. This dump is not affiliated with them.
- Do not treat this as a playable port, a replacement executable, or permission to redistribute the game.

If you use a virtual address from this dump in a mod, you are responsible for testing it on your own binary (retail vs no-CD builds differ).
